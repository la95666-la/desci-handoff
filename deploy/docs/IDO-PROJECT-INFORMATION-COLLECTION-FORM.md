# JoinCare IDO 项目资料收集表

> 本表用于项目申请上线 JoinCare IDO。请项目负责人完整填写，并按文末附件清单一并提交。  
> 标记说明：**必填**＝缺失则无法进入审核；**条件必填**＝符合对应情况时必须提供；**选填**＝建议提供，有助于审核和页面展示。  
> 除特别注明外，项目资料可能用于项目审核、IDO 参数配置和公开项目页面。身份证件、企业证照、联系方式等审核资料不会作为公开展示内容。

## 一、填写前须知

1. 请使用中文填写；面向国际用户展示的内容请同时提供英文版本。
2. 钱包地址、代币地址、募资参数和解锁计划在链上项目创建后不能随意修改，请至少由两名项目成员交叉核对。
3. 金额请填写正常可读数值，例如“10,000 USDT”，不要填写区块链 raw unit。
4. 所有时间必须同时注明时区，建议统一使用 UTC；例如：2026-10-01 12:00 UTC。
5. 项目方钱包必须由项目方独立控制。不得提供私钥、助记词或 Keystore 文件，JoinCare 不会索要上述信息。
6. 项目方应确保提供的信息真实、准确、完整，并有权使用所提交的文字、图片、商标、研究材料和代码。
7. 本表不构成法律、税务、投资或证券意见。项目方应自行取得适用司法辖区所需的专业意见和许可。

### IDO 项目币准备量

理论上覆盖硬顶所需的项目币数量为：

    硬顶对应项目币数量 = Hard Cap ÷ 每枚项目币价格

示例：

    Hard Cap = 100,000 USDT
    每枚项目币价格 = 0.10 USDT
    至少需准备 = 1,000,000 枚项目币

| 项目 | 项目方填写 |
|---|---:|
| 覆盖 Hard Cap 所需项目币 |  |
| 计划存入 IDO 合约的项目币 |  |
| 额外安全余量 |  |
| 项目方钱包当前可用余额 |  |

建议存入足够覆盖硬顶的项目币。仅覆盖软顶可能导致软顶以上的合法购买因 reserve 不足而失败。最终所需 raw 数量由平台按代币 decimals复核。

### 平台上线前阻断项

出现以下任一情况，不得创建或激活链上项目：

- 项目方身份、授权或钱包控制权未验证；
- 项目代币地址、decimals、特殊权限或源码无法确认；
- 项目代币存在不兼容的转账税、rebasing 或异常到账行为；
- Soft Cap 高于 Hard Cap，或 Max Per User 高于 Hard Cap；
- 开始时间不在未来，结束时间不晚于开始时间；
- 解锁时间不递增、早于结束时间或比例不等于 100%；
- 项目币余额不足，或没有完成对 IDO 合约的授权和存入；
- 支付币不在平台允许列表；
- 项目方钱包、募资款地址或多签信息不一致；
- 链上参数与项目方最终书面确认不一致；
- 存在未解决的重大法律、合规、知识产权、科研伦理或安全问题；
- 文案存在虚假、误导、固定回报、保本或未经授权的背书表述。
