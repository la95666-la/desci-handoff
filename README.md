# JoinCare DeSci — 公开源码快照

本目录是五个模块的独立脱敏副本。[来源提交](SOURCE-REVISIONS.md)仅用于溯源，不代表本快照与原始提交逐字节相同。

- 不附带预置管理员账号、默认密码、测试网签名私钥或钱包示例助记词。需要验证后台登录时，仅在隔离的本地环境另行配置测试管理员。
- 公开版的管理员初始化 SQL 保留表、角色与权限定义，移除了预置账号；本地测试基线及其校验清单已同步。**不得用于已运行原始迁移的数据库，不得更新现有迁移账本来接受这些校验值。**
- 仅供源码审阅和离线验证，不是生产发布制品。参见[发布边界](deploy/DEPLOYMENT_GUIDE.md)。
